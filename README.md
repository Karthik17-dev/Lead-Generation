# ⚡ Zed – The AI Command Center

> Autonomous B2B Lead Generation, Google Maps Intelligence, 5,500+ Pipedream Connectors, and Multi-Router AI Outreach Orchestration.

---

## 🌟 Key Features

- 🤖 **Zed Pro Multi-Router Gateway**: Dynamic model routing across FreeLLMAPI Render, OpenAI, Anthropic, and DeepSeek.
- 📍 **Google Maps Intelligence**: Deep prospect scraping with verified emails, phones, and addresses.
- 🔌 **5,500+ Suna / Pipedream Connectors**: Pre-configured connectors for Gmail, Slack, HubSpot, Salesforce, Apollo, Instantly, Lemlist, and developer tools.
- 📊 **Multi-Format Campaign Export**: Export directly to CSV, JSON, Markdown, and Excel tables.

---

## 🚀 Running Locally

```bash
pnpm install
pnpm --filter @zed/web dev --port 3001
```

Access the dashboard at [http://localhost:3001/projects/default](http://localhost:3001/projects/default).
